# Goethe B1 Hören & Lesen answer sheets

A small, offline answer sheet for listening and reading practice. Works in a modern browser on **Windows, Linux, and macOS**. No installation, account, server, or internet connection is needed.

## Open the app

Download this project (on GitHub, choose **Code → Download ZIP** and extract it). Double-click **index.html** to open it in your default browser. If needed, right-click the file and choose **Open with** Chrome, Edge, Firefox, or Safari.

## Use it

1. Choose **Hören (Listening)** or **Lesen (Reading)**, then enter an optional practice test name and date.
2. Play your practice audio or read your practice texts separately and select your answers.
3. Enable **Grade my answers** to compare with your answer key. Mark each answered question **Correct** or **Wrong**. Only one mark can be selected; uncheck it to return to ungraded. The total shows correct answers out of 30, a rounded percentage, and the number still ungraded. Changing or clearing an answer clears its grade. Turning grading off hides the controls and keeps your marks.
4. Choose **Save answers .txt** to download a permanent copy, or **Print / PDF** to print the sheet or save it as a PDF using your browser's print dialog.
5. Choose **New sheet** when you are ready for another practice session. You will be asked before the current sheet is cleared.

Grades save automatically alongside your answers. Text exports include your marks and score; printouts include them when grading is enabled. **New sheet** clears both answers and grades for the currently selected module. Hören and Lesen save independently, including test names, dates, and grades. Switching modules keeps your work in each one. The score stays provisional until all 30 questions have been graded.

The 30 Hören questions follow the [official Goethe B1 model test](https://bfu.goethe.de/b1_mod/hoeren.php):

| Part | Questions | Choices |
| --- | --- | --- |
| Teil 1 | 1–10 | Odd: Richtig / Falsch; even: a / b / c |
| Teil 2 | 11–15 | a / b / c |
| Teil 3 | 16–22 | Richtig / Falsch |
| Teil 4 | 23–30 | a / b / c |

The 30 Lesen questions follow the [official Goethe B1 Lesen model test](https://bfu.goethe.de/b1_mod/lesen.php):

| Part | Questions | Choices |
| --- | --- | --- |
| Teil 1 | 1–6 | Richtig / Falsch |
| Teil 2 | 7–12 | a / b / c |
| Teil 3 | 13–19 | a–j or 0 (no matching advert) |
| Teil 4 | 20–26 | Ja / Nein |
| Teil 5 | 27–30 | a / b / c |

Teil 3 uses a dropdown for each question. Each advert may be used only once; the advert used by the example is unavailable. The sheet lets you record choices freely; check these rules against your practice test yourself.

Use **×** beside a question to clear it. Keyboard users can Tab between questions and use arrow keys to select an answer.

Your current sheet saves automatically in this browser when browser storage is available. Keep the HTML file in the same location and use the same browser to return to it. Private browsing, clearing browser data, moving the file, or browser restrictions can remove or prevent saved progress; the app displays a message when saving fails. Download a text copy to keep past sessions or move your answers to another device. Text exports are for reading and cannot be imported back into the app.

This is an independent practice tool, not an official Goethe-Institut product. It records answers and supports manual self-grading; it does not include audio, exam questions, or an answer key.

## Project

The entire app is in `index.html`, using plain HTML, CSS, and JavaScript, with no external dependencies or network requests. Edit it in any text editor and reopen or refresh the page.
